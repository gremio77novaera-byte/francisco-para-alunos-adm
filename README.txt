FRANCISCO PARA ALUNOS — PAINEL ADMIN V1

O que esta versão já demonstra:
- Login administrativo separado.
- Criação de anos/séries (6º, 7º, 8º, 9º, 1ª série, etc.).
- Criação opcional de turmas A, B, C dentro de cada ano.
- Login específico opcional para cada turma.
- Avisos direcionados para toda a escola, um ano/série ou uma turma.
- Playlist por ano/série (compartilhada entre as turmas daquele ano).
- Jogos por ano/série (compartilhados entre as turmas daquele ano).
- Alteração do usuário e senha do administrador.

ATENÇÃO:
Esta V1 é um protótipo local. Ela guarda os dados no navegador (localStorage).
Isso NÃO é suficiente para uso real pela gestão, porque outro computador não verá as alterações.

PRÓXIMA ETAPA:
Conectar este painel e o site dos alunos a um banco online gratuito e autenticação segura.
Depois disso:
ADMIN -> salva -> banco online -> todos os alunos veem a atualização.
